# WeatherPlus

Aplicación web desarrollada para consultar información climática en tiempo real utilizando la API de OpenWeather.

## Descripción

WeatherPlus permite buscar ciudades y visualizar información climática actualizada dinámicamente, mostrando datos como temperatura, humedad y estado del clima.

Este proyecto fue desarrollado con el objetivo de fortalecer conocimientos en consumo de APIs REST, manipulación del DOM y desarrollo frontend con JavaScript.

---

## Características

- Consulta climática en tiempo real
- Pronóstico climático para los próximos 5 días
- Búsqueda dinámica de ciudades
- Geolocalización para detectar ubicación del usuario
- Cambio de temperatura entre Celsius y Fahrenheit
- Manejo de errores para ciudades inválidas o fallos de conexión
- Visualización de temperatura, humedad y condiciones climáticas
- Consumo de API REST usando Fetch API

## Conceptos Aplicados

- Manipulación dinámica del DOM

## Instalación

1. Clonar el repositorio

```bash
git clone https://github.com/SamuCodev/WeatherPlus.git
```
2. Abrir la carpeta del proyecto
3. Ejecutar index.html
